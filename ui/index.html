    Setting up

    1. ntfy: install the ntfy app, subscribe to a long random topic, and enter that topic. Self-hosted or protected topic: also the server and an access token.
    2. Pushover: create an application on pushover.net and enter its token plus your user key.
    3. Telegram: make a bot with @BotFather, send it a message, then enter the bot token and your chat ID.
    4. Choose what to get a push for, and after how many minutes a reminder comes for something still waiting.

    Settings are per workspace, keys are in the OS key store. Without "details" a push only names the task, not the question.
